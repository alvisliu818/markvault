## 数据流

1. **写**：前端编辑 → 防抖 900ms → `POST /api/file/putFile` → 先快照旧内容 → vault.rs 写文件 → `ops::reindex_one` 重索引该文件 → WS 广播 `doc-reindexed`/`filetree-changed`。
2. **外部改**：notify-debouncer-full 监听 vault → 过滤 `.` 目录与 ignore 模式 → 对 .md reindex_one / unindex；**目录级事件（新建/删除/改名）走精确 prefix 重索引**（旧路径 `unindex("<dir>/")` 防兄弟目录误删，新路径 `reindex_prefix` 扫描重建）→ 广播。`.markvault/` 完全跳过避免自触发。注意 `vault.rel` 需容忍 debouncer-full 的 forward-slash verbatim 路径（`//?/E:/...`）——字符串级前缀回退在 vault.rs normalize_win。
   - v0.3 修复：debouncer 原先是 `start_watcher` 的栈上局部变量、函数返回即 drop，**watcher 自 v0.1 起从未真正工作**；boot 全量索引 + API 内部 reindex 掩盖了这一点。修法是把所有权移入工作线程，并补「外部改名 → 索引路径变化」E2E 断言。
3. **关系树**：`/api/vt/getRelationTree` 时从索引读全部 docs（frontmatter `parent`/`weight`）→ 解析 wikilink（路径精确 > 标题 > 基名）→ 构树（ancestors 环检测、分支复制）→ 兄弟消歧 → 排序（customOrder > weight desc > name asc）→ 返回树 JSON。结构不持久化，只持久化意图（roots/拖拽序/设置，`vt.json`）。
4. **剪藏**：`/api/clip/clipUrl` → reqwest 拉取 → dom_smoothie(Readability) → htmd → 拼 frontmatter（source/created/tags）→ `create_doc_internal` 复用建文档路径（写入+索引+广播）。登录页由客户端供 HTML 走 `clipHtml`。
5. **内嵌浏览器（M6）**：SPA 浏览器面板 = 控制器（页签列表/地址栏/前进后退/剪藏/收藏/下载），壳 `browser.rs` = 窗口组管理。页签窗口 URL/title 由壳轮询并以 `browser:*` 事件推回主窗口；SPA 收到 url 变化即 `POST /api/history/add`（内核 10min 去重+5000 上限）。页面内操作（收藏/剪 HTML）由壳 eval 注入的操作栏完成——页面上下文 fetch 内核（本地 Host 信任放行 + CORS very_permissive），登录页 DOM 内核拿不到，这正是 `clipHtml` 存在的理由。Tauri eval 不受页面 CSP 限制，但页面内 fetch 受 connect-src 约束，严格 CSP 站点需回退面板 `clipUrl`。
6. **关系图谱（M11）**：`/api/graph/getGraph` 返回 docs 全量节点 + links 表经 resolve_target 解析的 doc→doc 边（未解析目标跳过）；前端 panels/graph.ts 手写力导向（斥力/弹簧/中心引力/alpha 衰减 + 画布软边界），节点点击打开文档、拖拽钉住、滚轮缩放。hidden dock 页 canvas rect=0 → IntersectionObserver 首次可见才加载。
7. **快照历史（M11）**：`/api/repo/*` + `.markvault/repo/<sha256(path)16>/<millis>-<chash8>.md` 内容寻址存储（同内容去重、每文档 30 版上限）。putFile 写前自动留存旧内容；restore 前自动留存当前内容。前端「历史版本」对话框（文件树右键 / 编辑器工具行）列表+预览+恢复。plaintext MVP，加密未做。
8. **插件系统（M11）**：`.markvault/petal/petals.json` 注册表（[{name,enabled}]）+ 每插件 conf.json；`/api/petal/loadPetals|setPetals|getPetalConf|setPetalConf`；内核 ServeDir 只读托管 `/petal/<name>/`；前端 petal/loader.ts 动态 import index.js（default export class，构造收 host，onload/onunload 生命周期），宿主暴露 api/ui/getActiveDoc/insertToActiveDoc/addCommand；工具栏「命令」按钮列全部插件命令。信任模型 = 用户自装插件（思源同），加载即执行任意 JS。
9. **多工作区（M11 路线 A）**：壳 `workspace.rs` 维护实例池（每个 vault 一个内核进程、随机端口、最多 3 个 LRU 淘汰）。`ws_switch` 启动/复用目标实例后让**主窗口 navigate 到目标内核 URL**，SPA 与前端数据层零改动；同时同步 `BrowserState.kernel_origin`（注入栏回连地址）与 `AppMeta.workspace`。主窗口销毁时回收全部实例。

## 设计决策与取舍

- **文件为真相，SQLite 是缓存**（仿思源 `temp/` 数据库）：`.markvault/cache/index.db` 删了就重建；启动按 `index_meta`（mtime+size）增量跳过，手动 rebuild 强制全量。
- **文档身份 = 相对路径**（Obsidian 风格），非思源的 `.sy`+ID。块 ID（`^id`）入索引表，`[[doc#^id]]` 块引用已端到端打通。
- **关系树服务端计算**：两插件都在前端全量扫库；内核有索引后移到服务端，前端只渲染。与 siyuan-virtual-tree 的"关系树只读派生 + 拖拽序持久化"语义一致。
- **行级解析而非完整 AST**：索引用轻量行解析（frontmatter/标题/块id/wikilink），HTML 渲染用 comrak。权衡：解析快且可控；代价是嵌套块级结构（列表树）暂不作为块索引。
- **Tauri 而非 Electron**：内核分离架构下桌面壳只是"窗口 + 内核子进程管理"，Tauri 体积小；嵌入浏览器用多 WebviewWindow 方案（M6 路线，Tauri v2 无嵌套 webview）。
- **remote 主窗口授权**：SPA 从内核 URL 加载属 remote origin，默认够不到自定义 IPC → `withGlobalTauri` + `capabilities/main.json` 逐个 `allow-*`；新增命令须同步 handler / build.rs / capabilities 三处。
- **伺服安全**：默认绑 127.0.0.1；networkServe 绑 0.0.0.0 后由 accessAuthCode + HMAC cookie 保护；apiToken 走 `Authorization: Token`；`/vault/*` 静态路由拒绝任何点开头路径段（保护 `.markvault`）。
- **多工作区选壳侧实例池而非单实例多 vault**：切换 = 换 URL，SPA 无需感知工作区；代价是每 vault 一个内核进程，故限制 ≤3 并用 LRU 淘汰。
- **快照先做明文本地 MVP**：内容寻址 + 30 版上限解决"误改回滚"，加密与跨设备同步（LiveSync/CouchDB）留待密钥管理方案确定后再做。
- **CI 应要求关闭**（v0.3）：删除 GitHub Actions workflow，验证链保留在本地 `cargo test` + `clippy` + `node e2e/check.mjs`。

## 已知限制（截至 v0.3）

- 内核侧剪藏无法携带浏览器 cookie（登录页不可剪）——嵌入浏览器注入栏走 `clipHtml` 在页面上下文取 DOM 解决；但严格 CSP 站点（connect-src 收紧）会拦截注入栏的 fetch，回退面板「剪藏」（clipUrl）。
- networkServe 伺服模式下，浏览器窗口内注入栏 fetch 内核不带访问码 cookie（外部页面无登录态），剪藏/收藏会 401；本地模式不受影响。
- 注入操作栏的样式受页面 CSP style-src 影响（个别站点可能裸样式），功能不受影响。
- **Tauri mobile 未做**：仅交付 SPA 响应式（≤860px 抽屉），Android/iOS 构建需对应 SDK（本机 Windows 只能走 Android 路线）。
- **同步与加密未做**：本地文件级快照为明文 MVP；LiveSync（CouchDB）对接、repo/ 与 petal 存储的加密均留待后续；`.sy` 导入/导出用户决定不做。
- **壳内交互需人工点验**：浏览器多页签/注入栏、多工作区切换、vault 选择对话框、开机自启、preview `/#/doc/` 在 WebView2 内的 hash 路由——E2E 跑在同类 Chromium 内核的浏览器环境，触不到 Tauri IPC。
- **目录改名后 vt 挂载树不跟随**：v0.3 修了索引精确性，但挂载树中该目录下的节点会 missing，需手动重挂。
- **版本号未统一**：`tauri.conf.json` 仍 `0.2.0`、两个 `Cargo.toml` 仍 `0.1.0`、README/报告口径为 v0.3；正式发版需同步为 `0.3.0` 并重打 NSIS 安装包。
