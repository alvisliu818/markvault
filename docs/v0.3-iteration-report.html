fbdcc88
v0.3 · 第一轮

M6 ✓内嵌浏览器（Tauri 多窗口方案）

  • 壳侧：Tauri v2 无嵌套 webview → 每个页签一个 WebviewWindow（label browser-<tabId>）；browser.rs 提供 6 个 IPC 命令（open / navigate / act / close / focus / list）+ 500ms 轮询上报 url/title（browser:opened|url|closed 事件）
  • SPA：浏览器面板只做控制器——地址栏补全（http/https/搜索词 → Bing 回退，移植 siyuan-plugin-browser normalizeUrl）、前进/后退/刷新/停止、页签切换与激活
  • 剪藏 / 收藏 / 下载：窗口内注入操作栏（window.__mvBar 防重、轮询重注入）；收藏 → /api/bookmark/add，剪 HTML → /api/clip/clipHtml，下载 → 新增 /api/asset/downloadToLocal（URL basename 解码 / 非法字符过滤 / -2 防覆盖）
  • 历史：.markvault/storage/browser-history.json + /api/history/list|add|remove|clear，10 分钟内同 URL 去重更新、5000 条上限截尾（对齐 siyuan historyStore，含 5 个单测）

两个边界：①Tauri eval 注入不受页面 CSP 限制，但页面自身的 fetch 受 connect-src 约束 → 严格 CSP 站点的注入栏会报网络错误，回退面板 clipUrl；②主窗口从内核 URL 加载属 remote origin，默认够不到自定义命令 → capabilities/main.json 显式授权 13 个 allow-* + withGlobalTauri。

9787645
v0.3 · 第二轮

FIXwatcher 地基返修 + 壳侧设置

  • 两个潜伏 bug：start_watcher 的 debouncer 是栈上局部变量、函数返回即 drop → watcher 自 v0.1 起从未真正工作；debouncer-full 把路径归一成 //?/E:/...，Windows path parser 不认，vault.rel 的 strip_prefix 全部失败
  • 目录级事件：新建 / 删除 / 改名走精确 prefix 重索引（旧路径 unindex("dir/") 防兄弟目录误删，新路径 reindex_prefix），不再退化为「全量结构广播」
  • 语义对齐：listDocsByPath 的 folder subFileCount 由全递归计数改为直接子文档数（LIKE dir/% AND NOT LIKE dir/%/%），与 Obsidian 版一致
  • M10 壳设置：pick_vault_dir（rfd 原生目录对话框）→ set_workspace 写 %APPDATA%/markvault/config.json；set_autostart 写 HKCU Run 键；SPA 设置面板新增壳区与工作区区

为什么拖到现在：boot 全量索引 + API 内部 reindex 把「外部改文件没有自动更新」完全掩盖了——只有端到端断言「外部改名 → 索引路径变化」能抓现形。修法：debouncer 所有权移入工作线程，路径用 normalize_win 字符串级前缀回退。

踩坑与沉淀

7 条可复用教训
类别问题破案手段 → 规则
生命周期 · 监听

debouncer 是 栈上局部变量，函数返回即 drop，watcher 自 v0.1 起从未重索引外部改动

boot 全量索引 + API 内部 reindex 掩盖；端到端断言「外部改名 → 索引路径变化」抓现形

规则：监听器所有权与工作线程同寿；后台链路必须有外部触发型 E2E
Windows · 路径

debouncer-full 输出 //?/E:/... verbatim，与 canonicalize 的 \\?\E:\... 用 strip_prefix 全部失配

逐路径打印 vault.rel 返回值

规则：normalize_win 去前缀 + 字符串级前缀回退，不依赖 OS path parser
Tauri · 权限

SPA 从内核 URL 加载属 remote origin，默认无法调用自定义命令

build.rs 声明 13 个命令生成权限，capabilities/main.json 逐个 allow-* + withGlobalTauri

规则：新增 IPC 命令三处同步（handler / build.rs / capabilities）
CSP · 剪藏

Tauri eval 可注入，但页面内 fetch 受 connect-src 限制，严格 CSP 站点注入栏失败

页面上下文与内核上下文分别验证

规则：注入栏失败时回退面板 clipUrl；登录页才走 clipHtml
canvas · 隐藏页

hidden dock 页 rect = 0，fitCanvas 的 Math.max(50, …) 把 backing store 钉死在 50px

canvas 尺寸与节点位置同时异常

规则：IntersectionObserver 首次可见才初始化，再进入唤醒模拟
API · 命名

getConf 输出 snake_case、SPA 读 camelCase，设置面板 escapeHtml(undefined) 报错（v0.2 潜伏）

补设置面板 E2E 断言后暴露

规则：手写 camelCase 视图，磁盘格式零迁移；新 UI 必进 E2E
语义 · 计数

subFileCount 对 folder 全递归计数，与 Obsidian 版「直接子文档数」不一致

跨版本功能对照

规则：count_md_direct 双 LIKE（dir/% + 排除 dir/%/%），E2E 断言防回归
